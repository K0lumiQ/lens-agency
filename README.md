# Lens agency

Сайт маркетингового агентства для B2B-компаний. Три страницы, вёрстка по макету pixel-to-pixel на трёх ширинах. Чистые HTML/CSS/JS, без сборщика.

- Макет: архив «Lens (Copy).zip» (JPG/PNG-экспорт) лежит в `design/` (в репозиторий не попадает, см. `.gitignore`). Для каждой страницы есть десктоп 1440, планшет 768 (экспорт 1440 px = ×1.875) и мобильная 390, плюс макет мобильного меню.
- GitHub: https://github.com/K0lumiQ/lens-agency
- Опубликовано: https://k0lumiq.github.io/lens-agency/

## Запуск

```
npx http-server -p 5177 -c-1 .
```

Можно открыть и просто `index.html`: пути относительные.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Hero с линзой, клиенты, «Не конвейер», подход (6 шагов), форма анализа, услуги, ниши, особенности B2B, форма «Делимся знаниями», кейсы, ценообразование, CEO, СМИ, блог, FAQ, финальная форма, подвал |
| `about.html` | О компании: миссия, рейтинги, форма заявки |

| `cases.html` | Кейсы: три проекта с задачей, описанием и результатами (якоря `#case-1…3`, на них ведут кнопки «Кейс» с главной) |
| `blog.html` | Блог: три статьи (якоря `#post-1…3`) |
| `privacy.html` | Политика конфиденциальности (ссылка из форм и подвала) |

## Адаптив

| Ширина | Что происходит |
|---|---|
| ≥1440 | точный макет 1440 (проверено наложением: высота страниц и позиции блоков совпадают с макетом в пределах нескольких px) |
| 1280–1439 | тот же вид, сетки резиновые |
| 1024–1279 | то же, из шапки убраны телефон и соцсети |
| 768–1023 | планшет по макету 768: 2 колонки у шагов, ниш, особенностей, уменьшенные шрифты |
| ≤767 | мобильная по макету 390: одна колонка, бургер-меню (выезжающая панель) |
| 320–359 | отдельные поправки |

Горизонтальной прокрутки нет ни на одной ширине от 320 до 1920 (проверено скриптом).

## Анимации и интерактив

Появление блоков при прокрутке (IntersectionObserver), лёгкий параллакс hero, шапка становится стеклянной и фиксируется после прокрутки, подчёркивание пунктов меню, подъём кнопок и подпись «Кейс →» со сдвигом стрелки, увеличение фото ниш и блога, подъём карточек цен, плашка «Digital маркетинг…» с наклоном, FAQ-аккордеон (плавная высота, крест превращается в «×»), бургер и выезжающая панель с закрытием по фону и Esc, вращающееся кольцо и пульсирующая галочка на «О компании», покачивание трубки и бегущие стрелки. Формы: маска телефона `+7 (___) ___-__-__`, проверка обязательных полей и e-mail, красная подсветка ошибки, тряска кнопки, сообщение «Заявка отправлена ✓» (серверной части нет, это демо). При `prefers-reduced-motion` анимации отключаются.

## Структура

```
index, about, contacts, cases, blog, privacy (.html)   страницы (собраны скриптом, правятся напрямую)
css/styles.css       токены в :root, шапка, кнопки, формы, секции главной
css/pages.css        точная подгонка под макет 1440 + страницы «О компании» и «Контакты»
css/responsive.css   резиновый десктоп, планшет, мобильный
js/main.js           появление, шапка, меню, FAQ, маска телефона, формы
assets/img/          фоны hero (desktop/tablet/mobile), логотипы клиентов, фото ниш, иконки, CEO, блог
assets/icons/        иконки соцсетей из макета
design/              макеты (только локально)
```

## Что нужно знать

- **Шрифты.** В макете текст набран платным гротеском (похож на Gilroy). Подобран ближайший бесплатный: Jost (с лёгким letter-spacing), заголовки Ubuntu. Подключены через Google Fonts, нужен интернет. Для автономной работы скачать файлы в `assets/fonts` и подключить через `@font-face`.
- **Картинки из макета.** Исходников не было, только плоские JPG. Hero-фон, фото ниш, логотипы клиентов, иконки и свечение сделаны вырезкой из макета; текст с фонов аккуратно убран. Если у клиента есть исходники, заменить файлы в `assets/img/` с теми же именами.
- **Заглушки.** Тексты кейсов, статей и политики написаны для примера, их нужно заменить реальными. Ссылки на Telegram (`t.me/lens_agency`) и Instagram — условные.
- **Формы** ничего не отправляют: подключить свой обработчик в `js/main.js` (блок «forms»).

## Как адаптировать под клиента

1. Цвета: `:root` в начале `css/styles.css` (`--bg`, `--purple`, `--line` и др.).
2. Тексты, телефоны, почта, ссылки на соцсети: прямо в HTML (в шапке, подвале и мобильном меню).
3. Логотип: `assets/img/logo.png` (вырезан из макета), лучше заменить на SVG.
4. Цены и кейсы: блоки `.price` и `.case` в `index.html`.
